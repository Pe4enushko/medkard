# scripts/

`audit-one-c-period.py` лежит в корне и остаётся там: это боевой прогон аудита,
на нём висит крон, и путь к нему менять нельзя.

Остальное разложено по тому, **зачем его запускают**:

| Папка | Что там | Признак |
|---|---|---|
| `operator/` | рутина эксплуатации: ключи API, отчёты, переаудит сломанных карт, разовые дозаливки данных | запускают руками по делу, пишут в боевую базу |
| `knowledge/` | обновление базы знаний: клинреки (PDF → чанки → эмбеддинги), реестр лекарств ГРЛС, реестр БАД СГР | меняют справочники, а не карты |
| `checks/` | сверки и диагностика: целостность справочников, детерминированность выдачи, метрики, воспроизведение запроса к 1С | ничего не меняют, только смотрят |
| `smoke/` | прогнать живой контур: пуш карт, роуты `/visits`, прогон на кэше 1С | нужен поднятый API или стенд |
| `hacks/` | временные заплатки, живущие до починки источника | у каждой в шапке написано, когда её сносить |

Костыли держатся отдельно намеренно: по папке видно, что это не часть системы,
а долг. Сейчас там демо-врачи — 1С не шлёт ФИО и коды врачей, без них нечего
показывать в персональных отчётах; см. `docs/visits-api.md`.
