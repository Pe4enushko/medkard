# Технический долг: удаление приёма из MedCheck

## Отсутствует маршрут удаления

В MedCheck отсутствует API-маршрут для удаления приёма по `Прием.GUID` и коду
организации. Поэтому удаление или отмена приёма во внешней МИС или 1С не
удаляет ранее переданные данные из MedCheck и «Искры».

## Критерий устранения

Необходимо реализовать аутентифицированный идемпотентный маршрут удаления
приёма, который принимает `Прием.GUID` и код организации и удаляет связанные
данные из MedCheck и «Искры».
