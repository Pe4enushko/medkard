# Форма 025/у: состав записи приёма

Приказ Минздрава РФ **от 13.05.2025 № 274н**, приложение 1 — учётная форма
025/у «Медицинская карта пациента, получающего медицинскую помощь в
амбулаторных условиях». Действует **с 01.09.2025 по 01.09.2031**, заменила
форму по приказу 834н от 15.12.2014. Поправок нет.

Вычитано 2026-08-31 по OCR всех 59 страниц, ключевые места сверены по
отрендеренным страницам.

Это **форма того документа, записи которого нам присылает 1С**. Более прямого
источника требований к составу полей приёма не существует.

---

## 1. Раздел «Записи врачей-специалистов» — первичный приём

Состав строк формы, дословно и в порядке следования:

| Строка формы | Есть ли у нас |
|---|---|
| Дата осмотра | `Прием.DATE` |
| на приёме; на дому; фельдшерско-акушерском пункте; прочее | нет |
| Врач (должность, специальность) | `Прием.Врач` — строка ФИО, **без должности и специальности** |
| **Жалобы:** | слот `ДанныеОсмотра` |
| **Анамнез заболевания, жизни:** | слот `ДанныеОсмотра` |
| **Объективные данные** | слот `ДанныеОсмотра` |
| **Диагноз основного заболевания: код по МКБ** | `Диагнозы[]`, но **без роли** |
| **Осложнения: код по МКБ** (два слота) | роли нет |
| **Сопутствующие заболевания: код по МКБ** (три слота) | роли нет |
| **Внешняя причина при травмах (отравлениях): код по МКБ** | нет |
| **Группа здоровья** | нет |
| **Диспансерное наблюдение** | нет |
| **Назначения (исследования, консультации)** | слот `ДанныеОсмотра` |

| **Физиотерапия** | нет |
| **Листок нетрудоспособности, справка** | нет |
| **Льготные рецепты** | нет |
| **Информированное добровольное согласие на медицинское вмешательство, отказ от медицинского вмешательства** | нет |

## 2. Раздел «Медицинское наблюдение в динамике» — повторный приём

Отдельный раздел с **укороченным** составом, повторяющимся блоками:

Дата · Жалобы · Данные наблюдения в динамике · Назначения (исследования,
консультации) · Лекарственные препараты, физиотерапия · Листок
нетрудоспособности, справка · Льготные рецепты · Врач

**Анамнеза, объективных данных и диагноза с кодом здесь нет.**

Это нормативное основание для того, чтобы требования к полям различались по
типу визита. До сих пор различение «анамнез только не на повторном» держалось
на замере по 334 картам Алёнки — теперь у него есть источник, а не только
статистика.

## 3. Разделы, задающие роль диагноза и первичность

**«Лист записи заключительных (уточнённых) диагнозов»**: ФИО врача, должность,
специальность · Дата (число, месяц, год) · Заключительные (уточнённые) диагнозы ·
Код по МКБ · **Установленные впервые — 1, повторно — 2**.

Последняя графа — прямой прообраз нашего `Диагнозы[].ВыявленВпервые`.

**«Хронические заболевания, функциональные расстройства, иные состояния, при
наличии которых осуществляется диспансерное наблюдение»**: Диагноз · Код по МКБ ·
ФИО врача, должность, специальность · Дата начала диспансерного наблюдения ·
Дата прекращения диспансерного наблюдения.

**Группа крови · Резус-принадлежность · антиген K1 системы Kell · иные сведения
групповой принадлежности крови (при наличии).**

**Аллергические реакции на лекарственные препараты, пищевая аллергия или иные
виды непереносимости в анамнезе, с указанием типа и вида аллергической
реакции.**

## 4. «Лист учёта доз облучения при рентгенологических исследованиях»

Отдельный раздел формы: Дата проведения · Название рентгенологического
исследования · Доза облучения.

Приложение 2, п. 21: «В раздел "Лист учёта доз облучения при рентгенологических
исследованиях" вносятся сведения о полученных дозах облучения при
рентгенологических исследованиях».

---

## 5. Что это опровергает

### Бэклог п. 3 — эффективная доза «требование только с 01.09.2026»

Неверно дважды. Первый раз — потому что доза есть в форме протокола 560н
(«при наличии», см. `protocol-forms.md`). Второй — потому что **обязанность
вести Лист учёта доз действует с 01.09.2025** по 274н, независимо от того, какой
приказ регулирует сам рентген.

### `coverage-map.md`, утверждение 6 — «отметки об ИДС в записи приёма не требуется»

**Неверно.** «Информированное добровольное согласие на медицинское вмешательство,
отказ от медицинского вмешательства» — строка раздела «Записи
врачей-специалистов», то есть поле записи приёма. Ошибка была в том, что искали
в 1051н, который описывает ИДС как самостоятельный документ и про запись приёма
ничего не говорит.

### Структура диагноза — не «как правило», а форма

323-ФЗ ст. 70 ч. 6 задаёт структуру «основное / сопутствующие / осложнения»
с оговоркой «как правило», из-за чего требование помечалось как слабое. Форма
025/у делает её **строками формы** с фиксированным числом слотов: одно основное,
два осложнения, три сопутствующих, одна внешняя причина.

Требование перестаёт быть мягким. Но проверить его по нашим данным нельзя:
`Диагнозы[]` приходит плоским списком без роли. Это, вероятно, самый серьёзный
структурный пробел выгрузки после отсутствия направительного диагноза.

---

## 6. Кандидаты в правила

Детерминистичные, по нашим текущим данным:

| Правило | Условие | Основание |
|---|---|---|
| у визита есть хотя бы один диагноз с кодом МКБ | первичный приём | 274н прил. 1, «Диагноз основного заболевания: код по МКБ» |
| «Жалобы» непусты | любой приём | форма, оба раздела |
| «Анамнез заболевания, жизни» непуст | **только первичный** | форма, раздел «Записи врачей-специалистов» |
| «Объективные данные» непусты | только первичный | там же |
| «Назначения» непусты | любой приём | форма, оба раздела |
| при коде класса S или T есть код внешней причины (V–Y) | травмы и отравления | форма, «Внешняя причина при травмах (отравлениях): код по МКБ» |

Требуют полей, которых в выгрузке нет, — в бэклог: роль диагноза
(основное / осложнение / сопутствующее), группа здоровья, отметка о диспансерном
наблюдении, физиотерапия, листок нетрудоспособности, льготные рецепты, отметка
об ИДС, должность и специальность врача, место осмотра, лист учёта доз
облучения.
